One line per file or package: what it holds and where its guard tests are. The code map (`workbench.layers` and `workbench.contexts` in workflow.yaml, [workbench-files.md](workbench-files.md)) groups the same packages into contexts; `issue-cli codemap` and `issue-cli affected <slug>` read it from the code itself, so they are the place to look for imports and a change's footprint. This page says what each file is for. Moved here from CLAUDE.md, which links to it.
